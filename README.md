# prov

Övningsfrågor inför prov. Klicka på en fråga för att se svaret.

Sidan finns på https://neckfors.github.io/prov/

## Prov

- [Historia: Vikingatiden](vikingatiden/index.html) (Puls SO, s. 74-97)

## Lägga till ett nytt prov

1. Skapa en mapp, till exempel `geografi/`, med en `index.html`.
2. Lägg en länk till den i `index.html` i roten och i listan ovan.
